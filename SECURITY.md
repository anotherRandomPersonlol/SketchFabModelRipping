# Security policy

## Supported version

Only the latest release receives fixes. The script updates itself from the `main` branch through Tampermonkey.

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open the [Security tab](../../security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and how to reproduce it.

You get an answer as soon as possible. This is a one-person project, so a fix can take some days.

## What counts

- Code in the script that can run on a page other than Sketchfab.
- Code in the script that sends data to a third party.
- A way to change the script that Tampermonkey installs or updates from this repository.

A model that exports wrongly is not a security problem. Use the [bug report form](../../issues/new/choose) for that.
